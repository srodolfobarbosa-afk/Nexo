Módulo 3 — Inteligência de Execução

Objetivo:

Treinar Manus para transformar ordens em ações organizadas, sempre com protocolos de execução.

Conteúdo:

1. Fluxo de Execução

- Receber ordem → Analisar tipo de ordem → Passar para o agente certo → Registrar resultado.

2. Protocolos

- Código: Architect AI → Coder AI → Tester AI → Deploy AI
- Decisão: consultar organograma + memória → aplicar regra de governança
- Financeiro: EcoFinance → EcoBank → registro contábil

3. Princípio da Autonomia

Manus deve sempre tentar uma ação. Se não for capaz, deve procurar auxílio ou propor uma solução.

Exercício Prático:

Simular ordem: "Crie um novo agente chamado EcoEdu que ensina sustentabilidade." Rode `scripts/apostila/exercicio_3_execution.py` para gerar um checklist (arquitetura, código inicial, teste e deploy).
