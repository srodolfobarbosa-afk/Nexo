Apostila — Fase 2: Autonomia Operacional e Inteligência Adaptativa

Esta apostila contém 4 módulos que treinam a Manus para operar como uma entidade autônoma.
Cada módulo inclui objetivos, conteúdo e exercícios práticos (scripts em `scripts/apostila`).

Uso rápido:

- Ler cada `MODULO_X.md` em ordem.
- Rodar os scripts em `scripts/apostila/` para validar os exercícios.

Estrutura:

- MODULO_1.md — Estrutura de Funcionamento Interno
- MODULO_2.md — Organização de Dados e Memória
- MODULO_3.md — Inteligência de Execução
- MODULO_4.md — Sistema de Economia Digital

Os scripts são intencionalmente simples e podem ser estendidos para integrar agentes reais do repositório.
